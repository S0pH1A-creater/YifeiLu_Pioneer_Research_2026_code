How to read this file

  • What is here: only the big RMSE summary tables (indexes + compare Quick RMSE). No per-study 1/16 metric blocks, no 3-row rolling mini-tables.
  • Order: (1) ticker RMSE indexes for SPY → AAPL → MSFT; (2) compare notebooks by rolling mode none → monthly → daily, each with SPY → AAPL → MSFT.
  • Naming: TICKER — RMSE index… = one ticker, all regimes/models, three rolling columns. compare_rolling_MODE — TICKER — Quick RMSE table = one rolling mode + one ticker.
  • Rows: always regime order 2008–2009 → 2013–2014 → 2018–2019 → 2019–2020; within each regime models GBM → Merton → Heston–Merton → GARCH–Merton (16 rows).
  • Index columns: Regime, Model, RMSE for none / monthly / daily, best rolling (lowest RMSE), file (study markdown name).
  • Quick RMSE columns: #, Regime, Model, RMSE, MAE, Bias (model − market). Same contract sample per ticker (n=24, seed=42); lookback 6 months.
  • Numbers: lower RMSE/MAE is better. Bold RMSE in compare tables is the headline metric used for ranking.
